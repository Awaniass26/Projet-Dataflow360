# 📊 Analyse Exploratoire des Données (EDA)

Bienvenue dans la section dédiée à l'analyse exploratoire du projet Dataflow360. Cette partie regroupe l'ensemble des scripts et des notebooks utilisés pour comprendre, nettoyer et visualiser nos données avant leur intégration dans les modèles.

## 🛠️ Objectifs de cette section
- **Compréhension du Dataset** : Identifier la taille, les types de variables et les distributions.
- **Nettoyage des données** : Traitement des valeurs manquantes, des doublons et des anomalies (outliers).
- **Analyse de Corrélation** : Chercher les relations clés entre les différentes variables.

## 📂 Structure du dossier
- `notebooks/` : Contient les fichiers Jupyter (.ipynb) d'analyses graphiques.
- `scripts/` : Fonctions Python réutilisables pour le pré-traitement.
- `README.md` : Ce fichier de documentation.

## 📈 Principales observations (Insights)
*(Astuce : Vous compléterez cette partie au fur et à mesure de vos trouvailles)*
- **Volume** : Le jeu de données contient `X` lignes et `Y` colonnes.
- **Qualité** : Nous avons détecté `X%` de valeurs manquantes sur la variable `Nom_Variable`, traitées par [votre méthode, ex: imputation par la moyenne].
- **Constat clé** : Une forte corrélation a été observée entre la variable A et la variable B.

## 🚀 Comment lancer les analyses ?
Pour exécuter les notebooks d'analyse sur votre machine :
1. Assurez-vous d'avoir installé les dépendances du projet (`pip install -r requirements.txt`).
2. Lancez Jupyter Lab ou Notebook :
   ```bash
   jupyter notebook
   ```
3. Ouvrez le fichier `votre_notebook.ipynb` situé dans ce dossier.
